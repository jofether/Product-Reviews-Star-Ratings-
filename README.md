# Product Reviews Application

A React application showcasing product reviews with star ratings. Built with Vite and styled with Tailwind CSS.

## Features

- Display customer reviews with star ratings
- Responsive design
- Interactive star rating display
- User-friendly review cards

## Project Setup

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Project Structure

```
src/
├── App.jsx       # Main application component
├── main.jsx      # Application entry point
└── index.css     # Tailwind CSS styles
```

## Components

- **Star**: SVG star component for rating display
- **ReviewCard**: Individual review card component
- **App**: Main application layout with review list
